# Project Overview: BrainBox

BrainBox is a high-performance monorepo for managing AI interactions across multiple platforms.

## Architecture

- **Monorepo**: Turborepo
- **Dashboard**: Next.js 14 (App Router)
- **Browser Extension**: Manifest V3
- **Backend**: Supabase (PostgreSQL, Auth, RLS)
- **AI**: Google Gemini API

## Key Features

- **Platform Adapters**: Unified interface for 8+ AI platforms.
- **GlobalBrain**: Semantic search across all conversations.
- **Glassmorphism UI**: Premium visual experience.
- **Optimistic Updates**: Real-time feel with Zustand.
